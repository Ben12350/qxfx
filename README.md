# 心屿 · 情绪疗愈小站

一个本地运行的双语情绪宣泄空间。没有云端账号，不需要安装第三方依赖，倾诉内容保存在本机。

## 启动

双击 `启动小站.bat`，浏览器会自动打开：

```
http://127.0.0.1:8765
```

关闭黑色命令窗口即可停止小站。

电脑需要安装 Python 3。若浏览器没有自动打开，手动访问上面的地址即可。

## 功能

- 首次进入选择中文或 English
- 询问是否开启柔和环境音乐；进入后仍可随时开关
- 选择情绪标签并输入完整倾诉
- 根据“疲惫、委屈、焦虑、愤怒、难过、孤独、被压垮”等语境及工作、睡眠、关系线索生成安抚回信
- 语音输入：使用浏览器语音识别，建议使用最新版 Chrome 或 Edge，并允许麦克风权限
- 手写输入：支持鼠标、触控和手写笔，可撤销、清空，笔迹会随倾诉一起存入后台
- 回信可朗读，并提供呼吸放松引导
- 响应式布局，支持手机和电脑

## 记录位置

每次提交会写入：

```
data/vents.jsonl
```

每行是一条 JSON 记录，包含提交时间、心情、文字、回信和手写图片。记录不会上传到外部服务器。

## 运行要求

- Python 3.9 或更高版本
- 语音识别需要 Chrome / Edge，并由浏览器提供在线识别服务
- 手写笔迹是图片记录，不会自动转换成文字；文字内容由上方输入框负责

## 安全

小站不是心理咨询或紧急救援服务。当文字中出现自伤风险时，回信会优先提示联系可信任的人或当地紧急服务。
